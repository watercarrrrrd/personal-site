> 项目名称：个人展示网站（Personal Portfolio Site）
> 文档版本：v1.0
> 编写日期：2026-10-19
> 文档状态：评审通过

---

## 1. 项目背景与目标

### 1.1 项目背景

个人开发者在求职、技术交流、作品展示等场景中，长期缺乏一个统一、专业、可控的线上展示门户。传统的简历以 PDF 为主，信息承载有限、交互体验单一、无法动态更新；而依赖第三方博客平台或社交主页，又受限于平台模板、广告干扰与品牌不可控。

本项目旨在构建一个**纯静态的个人展示网站**，作为开发者本人的「线上名片」，一站式承载个人介绍、技能栈、项目作品与博客内容，支撑求职投递与技术交流两大核心诉求。

### 1.2 项目目标

- **形态**：纯静态网站，无需后端与数据库，可直接部署到任意静态托管服务。
- **视觉**：深色主题 + 星空动效，营造「技术感、沉浸感」的第一印象。
- **内容**：完整覆盖个人介绍、技能展示、项目展示、博客四大功能模块。
- **适配**：响应式设计，全终端（桌面 / 平板 / 移动端）良好体验。

### 1.3 项目价值

| 价值维度 | 说明 |
| --- | --- |
| 品牌价值 | 建立统一的个人技术品牌，通过视觉与内容形成差异化记忆点，提升专业形象与可信度 |
| 效率价值 | 一次维护、全端复用，替代重复整理简历；信息集中，降低求职沟通与介绍成本 |
| 成本价值 | 纯静态、零依赖、零后端，部署与运维成本趋近于零；内容手动更新，无平台订阅费用 |

## 2. 用户与场景分析

### 2.1 目标用户画像

| 用户类型 | 特征 | 使用场景 |
| --- | --- | --- |
| 面试官 / HR | 时间有限、快速浏览、关注技能匹配度与项目成果 | 收到简历链接后，快速评估候选人技术栈与项目经验是否匹配岗位 |
| 技术同行 | 关注技术细节、源码质量与实现思路 | 通过分享链接了解作者技术深度，进行技术交流或合作 |
| 开发者本人 | 需要持续维护内容、控制品牌呈现 | 更新个人简介、技能、项目与博客，作为长期个人门户 |

### 2.2 典型使用场景

1. **求职投递**：面试官收到简历中的网站链接，在 1~2 分钟内完成「首屏印象 → 关于我 → 技能 → 项目」的浏览，形成对候选人的能力判断。
2. **技术分享**：开发者将网站或某篇博客链接分享到技术社区，同行访问后快速定位到项目或博客内容，进行评论、转载或联系合作。
3. **同行交流**：开发者本人向他人展示自己的作品与能力，辅助线下/线上面试自我介绍，或作为个人主页放在社交账号签名位。

## 4. 界面需求分析

### 4.1 设计原则

1. **深色主题**：以深色背景为基调，营造沉浸、专业的技术氛围，同时降低长时间浏览的视觉疲劳。
2. **简洁现代**：留白充足、信息层级清晰，避免多余装饰，突出内容本身。
3. **流畅动效**：星空背景、滚动触发动画、过渡效果需顺滑自然，不喧宾夺主。
4. **响应式适配**：以移动优先为思路，在桌面 / 平板 / 移动端均保证可用性与可读性。

### 4.2 视觉规范

| 项目 | 规范值 | 说明 |
| --- | --- | --- |
| 背景色 | `#0a0e1a` | 页面主背景（深蓝黑） |
| 卡片背景 | `#141a2e` | 卡片 / 区块背景 |
| 主色（强调色） | `#4f8cff` | 链接、进度条、高亮元素 |
| 次强调色 | `#8ab4ff` | 主色的浅色变体，用于 hover |
| 文字主色 | `#e6eaf2` | 正文主文字 |
| 文字次色 | `#9aa4b8` | 辅助说明文字 |
| 星空粒子色 | `#ffffff` | 星空粒子基础色，可带透明度 |
| 圆角 | `8px` / `12px` | 卡片 12px，按钮 8px |
| 字体 | 系统字体栈 | `-apple-system, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif` |
| 字号 | 16px 基准 | 标题 32/24/20px，正文 16px，辅助 14px |
| 间距栅格 | 8px 基准 | 间距以 8 的倍数递增（8/16/24/32/48/64px） |
| 最大内容宽度 | 1080px | 内容容器最大宽度，居中布局 |

## 5. 技术可行性分析

### 5.1 技术选型表

| 维度 | 选型 | 理由 |
| --- | --- | --- |
| 结构 | 原生 HTML5（语义化标签） | 无需框架，语义化标签利于 SEO 与无障碍 |
| 样式 | 原生 CSS3（CSS 变量 + @keyframes） | 变量统一主题，动画无需依赖第三方库 |
| 交互 | 原生 JavaScript（ES6+） | 零依赖实现交互，体积小、易维护 |
| 动效 | Canvas 2D + CSS Transition/Animation | Canvas 实现星空粒子，CSS 实现过渡与进度条动画 |
| 图标 | 内联 SVG | 零外部请求，可自由控制颜色与尺寸 |
| 部署 | 任意静态托管（GitHub Pages / Vercel / Netlify） | 纯静态产物，部署零成本 |

### 5.2 关键技术难点与对策

| 难点 | 说明 | 对策 |
| --- | --- | --- |
| 星空性能 | 大量粒子实时绘制可能造成性能开销 | 限制粒子数量，使用 requestAnimationFrame 统一渲染，设备像素比适配，页面不可见时暂停动画 |
| 响应式适配 | 不同屏幕宽度下布局与导航的适配 | 媒体查询断点设计，移动端导航折叠，内容容器自适应宽度 |
| 滚动锚点偏移 | 吸顶导航遮挡锚点目标区块顶部 | 使用 `scroll-margin-top` 为各区块预留偏移量 |

### 5.3 目录结构说明

```

├── css/
│   └── style.css       # 全部样式（主题变量 + 布局 + 动画）
├── js/
│   └── main.js         # 全部交互逻辑（星空 + 导航 + 进度条动画）
```

## 6. 非功能性需求

### 6.1 性能需求

- 首屏内容渲染完成时间 < 2 秒（4G 网络下）。
- 星空动画稳定运行在 60fps，不阻塞主线程。
- 页面总体积（HTML + CSS + JS）控制在合理范围，无外部资源阻塞渲染。

### 6.2 兼容性需求

- 支持主流现代浏览器最新两个大版本（Chrome、Edge、Firefox、Safari）。
- 对不支持某些 API 的旧浏览器提供优雅降级，保证内容可读。

### 6.3 可维护性需求

- 代码结构清晰、注释完善，便于后续内容更新与二次开发。
- 使用 CSS 变量统一主题，换肤 / 调整配色只需修改变量。
- 内容与结构分离，新增项目 / 技能只需修改对应 HTML 片段。

### 6.4 无障碍需求

- 图片与图标提供替代文本。
- 语义化标签保证屏幕阅读器可正常解析页面结构。
- 足够的文字与背景对比度，保证可读性。
- 键盘可操作导航与链接。

## 7. 约束与假设

### 7.1 约束

- **纯静态**：不使用后端、数据库与服务器渲染。
- **零框架零外部依赖**：不使用 Vue/React 等框架，不引入 jQuery、动画库、字体 CDN 等任何外部依赖。
- **内联 SVG 图标**：所有图标以内联 SVG 形式呈现，不发外部请求。

### 7.2 假设

- 用户使用现代浏览器（支持 CSS Grid/Flexbox、ES6、Canvas）访问网站。
- 网站内容由开发者本人手动更新，不涉及自动化内容管理。
- 博客内容可能暂时为空，以占位形式呈现，后续逐步填充。

## 8. 风险分析

| 风险 | 影响 | 概率 | 应对 |
| --- | --- | --- | --- |
| 星空动画在低端设备卡顿 | 影响观感与性能评分 | 中 | 限制粒子数量，支持按设备性能降级或减少粒子 |
| 旧浏览器兼容问题 | 部分用户无法正常显示 | 低 | 提供 CSS 前缀与 API 降级方案，保证核心内容可读 |
| 内容长期未更新 | 信息陈旧，降低可信度 | 高 | 预留清晰的更新说明，内容结构化便于快速维护 |
| 锚点偏移导致导航定位不准 | 跳转位置被导航遮挡 | 中 | 使用 `scroll-margin-top` 统一解决 |
| 星空 Canvas 尺寸失真 | 高 DPI 屏幕模糊或拉伸 | 低 | 按 devicePixelRatio 缩放 Canvas，配合 ResizeObserver 自适应 |

## 9. MVP 验收标准

1. 页面在 Chrome、Edge、Firefox、Safari 四款主流浏览器上均可正常打开，**控制台无报错**。
2. 首屏内容（Hero 区）在 4G 网络下 **2 秒内完成渲染**，页面总体积不超过 100KB。
3. 星空动效在桌面端稳定运行，**平均帧率不低于 60fps**。
4. 响应式布局在 375px / 768px / 1440px 三种宽度下**无横向滚动条**，导航与内容均可用。
5. 七个功能模块（导航、Hero、关于我、技能、项目、博客、页脚）**全部可见且内容完整**，导航锚点点击后能正确定位到对应区块。
